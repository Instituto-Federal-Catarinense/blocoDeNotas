# blocoDeNotas

Projeto piloto: um bloco de notas simples com salvamento automático usando `localStorage`.

## Recursos

- Salva o conteúdo automaticamente enquanto você digita
- Carrega a última nota ao abrir a página
- Botão para limpar o conteúdo
- Validação de suporte a `localStorage`
- Mensagem de status para informar se as alterações foram salvas

## Como usar

1. Abra `index.html` no navegador.
2. Digite suas anotações no campo.
3. O texto será salvo automaticamente no navegador.
4. Clique em "Limpar notas" para resetar o conteúdo.

## Estrutura do projeto

- `index.html` — interface do usuário
- `style.css` — estilos responsivos e visuais
- `script.js` — lógica de carregamento, salvamento e manipulação de notas
