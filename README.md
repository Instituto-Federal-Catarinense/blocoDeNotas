# blocoDeNotas
Projeto piloto: um bloco de notas simples que salva automaticamente o conteúdo no navegador usando `localStorage`.

## Como usar

- Digite sua nota no campo de texto.
- O conteúdo é salvo automaticamente no `localStorage` do navegador.
- Use o botão "Limpar" para apagar a nota atual.
- Use o botão "Restaurar" para recarregar a última nota salva.

## Melhorias aplicadas

- HTML com estrutura acessível e botão de controle.
- JavaScript modular com tratamento de indisponibilidade de `localStorage`.
- CSS atualizado para um visual mais moderno e responsivo.
