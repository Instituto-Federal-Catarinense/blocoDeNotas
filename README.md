# blocoDeNotas

Projeto piloto: um bloco de notas simples que salva automaticamente o texto no navegador usando `localStorage`.

## Funcionalidades

- Salva o conteúdo enquanto o usuário digita
- Carrega as notas salvas automaticamente ao abrir a página
- Botão para limpar as anotações
- Feedback visual de salvamento

## Como usar

1. Abra `index.html` em um navegador.
2. Digite suas anotações no campo.
3. O texto é salvo automaticamente e reaparece quando a página é recarregada.
4. Use o botão "Limpar anotações" para apagar o conteúdo e o armazenamento local.
